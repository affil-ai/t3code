# T3 Work

> **Deprecated.** This fork is no longer developed. The only part still in use
> is the standalone chat bridge in [`apps/chat-bridge`](apps/chat-bridge/README.md),
> which runs against stock T3 Code
> ([`pingdotgg/t3code`](https://github.com/pingdotgg/t3code)).

Everything else in this repository (Work mode, Firstmate and Agents, the chat
dock, the desktop app and the other client and server changes) is deprecated.
Don't build on it, and don't build or run the fork's server or desktop app to
use the bridge.

To run the bridge, clone this repository (`affil-ai/t3code`), install the
workspace dependencies and follow
[`apps/chat-bridge/README.md`](apps/chat-bridge/README.md). It needs nothing
else from this fork.
